# Food Delivery Performance Analysis

تحليل أداء طلبات شركة توصيل وجبات، باستخدام بيانات أسبوعية للوجبات ومراكز التجهيز. يهدف المشروع إلى دعم التخطيط للطلب ومراجعة الأداء والعروض، مع توثيق القيود وعدم الجزم بالسببية من بيانات رصدية.

## الملفات

- `AGENTS.md`: قواعد المشروع والعمل على البيانات والتقارير.
- `notebooks/analysis.ipynb`: التحليل القابل لإعادة التشغيل.
- `docs/`: قرارات تنظيف البيانات واختبارات مهارات المشروع.
- `reports/`: تقرير العميل والعرض والرسوم.
- `.github/skills/`: مهارتان مخصصتان لحساب مؤشرات الطلب وكتابة تقرير العميل.

## تشغيل التحليل

من جذر المشروع ثبّت الاعتماديات بالأمر `python -m pip install -r requirements.txt`، ثم افتح الدفتر واختر نواة Python وشغّل الخلايا بالترتيب. ضع ملفات CSV المقدمة محلياً في `data/raw/` قبل التشغيل.

**لا يحتوي هذا المستودع على ملفات البيانات الأصلية.** مجلد `data/raw/` مستثنى من Git ويجب عدم تعديل ملفات المصدر أو رفعها. أرقام التقارير مصدرها دفتر التحليل.
