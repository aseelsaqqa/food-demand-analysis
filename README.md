# Food Delivery Performance Analysis

مشروع تحليل بيانات طلبات وجبات أسبوعية لدعم تخطيط الطلب ومراجعة مؤشرات المراكز والعروض. قواعد التعامل مع ملفات المصدر موثقة في [AGENTS.md](AGENTS.md).

## تشغيل التحليل

1. ثبّت الاعتماديات من جذر المشروع: `python -m pip install -r requirements.txt`.
2. افتح [دفتر التحليل](notebooks/analysis.ipynb) في Jupyter أو VS Code واختر بيئة Python مثبتاً فيها `ipykernel`.
3. شغّل خلايا الدفتر بالترتيب. يقرأ الدفتر ملفات CSV من `data/raw/` للقراءة فقط، ويتحقق من عمليات الربط والجودة، ثم يحسب المؤشرات والاختبارات وينشئ الرسوم في `reports/figures/`.
4. راجع [سجل قرارات التنظيف](docs/cleaning_decisions.md) و[تقرير العميل](reports/client_report.md). جميع أرقام التقرير مرتبطة بقسم وخلية كود في دفتر التحليل.

## البيانات وسلامتها

يحتاج التحليل إلى `train.csv` و`fulfilment_center_info.csv` و`meal_info.csv` ضمن `data/raw/`. يوجد أيضاً `test.csv` للتنبؤ الاختياري، ولا يحتوي على هدف الطلب `num_orders`. مجلد `data/` مستثنى من Git بواسطة `.gitignore`؛ لا تعدّل ملفات المصدر ولا ترفعها.

## ملخص النتائج

- يرتكز الطلب على مجموعة محدودة من الوجبات، مع نتائج تفصيلية ومصادرها في تقرير العميل.
- تختلف مؤشرات متوسط الطلب الأسبوعي بين أنواع مراكز التجهيز، وتُعرض بوصفها فروقاً وصفية.
- تظهر ارتباطات وفروق في بيانات الترويج والخصم، لكنها لا تثبت السببية.

الأرقام والرسوم والتوصيات مدعومة في [تقرير العميل](reports/client_report.md) و[دفتر التحليل](notebooks/analysis.ipynb). لا تستخدم هذا الملخص المختصر كمصدر مستقل للأرقام.

## استخدام الذكاء الاصطناعي

استُخدم مساعد تطوير ومهارة `python-fact-grounded-coding` للمساعدة في تنظيم دفتر التحليل والتحقق من الحسابات والرسوم. روجعت المهارات الجاهزة المتعلقة بالاستكشاف الأسبوعي والترويج بدلاً من تكرارها، وأُضيفت مهارتان مخصصتان ومختلفتان في `.github/skills/` لحساب مؤشرات الطلب وكتابة تقرير العميل. راجع [بحث المهارات الجاهزة وحالات الاختبار](docs/skills_test_cases.md). ينبغي إعادة تشغيل الدفتر والتحقق من نتائجه قبل تعديل التقرير أو استخدامه في قرار تشغيلي.
